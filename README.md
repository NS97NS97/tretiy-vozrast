# Третий возраст

Сайт для активных людей «третьего возраста»: **здоровье, финансы, путешествия,
творчество и живое общение**. Тёплый онлайн-журнал с карточками материалов и
тематический форум сообщества.

## Возможности

- 🌿 **10 готовых материалов** с кнопкой «Открыть материал» — по 6 направлениям:
  здоровье, развитие, финансы, развлечения, хобби, общение
- 🔍 **Поиск и фильтры** по категориям без перезагрузки страницы
- 💬 **Отдельный форум**: создание тем, ответы, счётчики просмотров и разделов
- 🖥 **Адаптивная вёрстка** — удобно на телефоне, планшете и компьютере
- 🎨 Современный светлый дизайн с плавными переходами

## Технологии

Python 3 · Flask · HTML · CSS · JavaScript (без внешних библиотек)

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

Откройте в браузере: http://127.0.0.1:5000

## Структура

```
app.py                 — маршруты + форум (данные в памяти)
content.py             — контент карточек (легко добавлять новые)
requirements.txt
templates/             — шаблоны страниц, логотип
static/css/style.css   — дизайн и адаптив
static/js/main.js      — меню, фильтры, плавные появления
```

Чтобы добавить материал, скопируйте любой словарь в `MATERIALS`
в файле `content.py` — карточка и страница появятся автоматически.
